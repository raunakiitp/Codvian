# AGENTS.md: scope of this repository

This repository (`raunakiitp/Codvian`) is CODVIAN's **public product-information hub only**.

## Allowed
- `README.md`, this `AGENTS.md`, and public-facing brand images in `assets/`.

## Not allowed, ever
- Application source code of any kind.
- Backend, API or database code, schemas, migrations or internal configuration.
- CODVIAN Desktop or VS Code extension source.
- Secrets, credentials, API keys, tokens, `.env` files or private URLs.
- Build artifacts, installers, VSIX packages, archives, `package.json` or dependencies.
- Using this repository as a development workspace.

## Where engineering work belongs
The permanent engineering repository is the private **`raunakiitp/Codvian-desktop`**. All CODVIAN engineering work
goes there.

## Changing this repository
A commit here requires an explicit user instruction that names the public `Codvian` repository. Without that
instruction, do not modify this repository.
